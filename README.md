# AP Physics 2 Tracker

A self-study tracker for AP Physics 2 (Nov 2026 → May 2027 exam): Units 9–15 at about three weeks each, then April for review and practice exams.

- Open `index.html` in a browser, or host it with GitHub Pages or Cloudflare Pages.
- Progress is saved in your browser (localStorage).
- Readings use the free [OpenStax College Physics 2e](https://openstax.org/details/books/college-physics-2e).
